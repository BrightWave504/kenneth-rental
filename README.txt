Kenneth Rental Shop - front-end demo

Open index.html in Chrome or Edge. Create a buyer account or use admin@kenneth.local / Admin123! for admin demonstration.

IMPORTANT: Browser localStorage is NOT secure. Passwords, stock credentials, and simulated wallet balances are stored locally, with no real authentication or payment verification. DO NOT deploy for real transactions. Build a backend with hashed user passwords, server-enforced role authorization, secure stock delivery, and verified payment webhooks first.
